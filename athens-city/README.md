# 雅典 · 卫城 — 像素主线游戏

从迪皮隆门进城，穿过泛雅典娜大道，爬上卫城，为这一夜点亮圣火的一场像素旅程。这是「拆分后」的**游戏一（雅典主线）**，独立播放、独立存档，不包含苏尼翁角（那是一个单独的游戏《苏尼翁角 · 海灯》）。

- **类型**：纯 Web 像素步行 + 对话 + 轻谜题 + 迷你游戏
- **技术**：原生 HTML5 Canvas，无构建、无外部素材（全部程序化像素画），localStorage 自动存档
- **存档键**：`athens.city.save.v1`（与苏尼翁游戏互不干扰）

## 运行

```bash
node serve.js     # 默认端口 8213
# 或：PORT=8302 node serve.js
# 或双击 start.bat
```

打开 http://127.0.0.1:8213/ 即可游玩。

## 玩法流程

1. **迪皮隆门 · 山门入园**：从凯拉米克斯经过入城检查（一次简短小关卡），拄着火炬进雅典城。
2. **古市集 → 卫城**：在雅典地图收集信息，顺着线索前往卫城。
3. **卫城探索**：帕特农、厄瑞克忒翁、雅典娜祭坛，找齐圣火三样材料（橄榄木 / 松脂 / 铜盆）。
4. **抉择 · 入夜**：决定用什么方式点火，决定会改写结局台词与图鉴。
5. **点火 · 圣火**：用「引雷 · 循光」记忆小游戏升起圣火。圣火点过后，比雷埃夫斯港的小船会告诉你——故事在这里告一段落。
6. **家 · 铜匠台**：猫、长椅，和一段收尾。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD / 方向键 | 移动 |
| Shift | 快走 |
| E / 空格 | 对话、互动、确认 |
| H | 回家（铜匠台） |
| M | 大地图 |
| J | 图鉴（三页：藏品 / 拍立得手账 / 旅程） |
| Esc | 菜单 |

小游戏「引雷 · 循光」：先用 **1 / 2 / 3**（或 **A / S / D**）记下祭司点灯的顺序，再按同样顺序还原。

## 玩法与系统

- **抉择结局**：点火方式影响收尾台词与图鉴词条。
- **橄榄油 · 以物易物**：在蒙纳斯提拉奇市集用收集的油换油灯等小物件。
- **拍立得手账**：在景点按 E 留影，自动存进图鉴第二页。
- **图鉴 / 奖杯**：收集条目越多，旅程页记录越好看。

# 本次改进 · v0.5-art.1

本版放在独立文件夹，重点解决「转绘与原图几乎相同」的问题。

1. **保布局，换媒介。**截图决定建筑相对位置、道路与水域；去掉像素台阶、方块轮廓与像素材质的保留要求，让画面用连续线条和新材质重绘。
2. **三种可选风格。**青绿绢绘强调矿物色和细笔，水墨留白强调墨色与纸白，纸雕光境强调纸层、景深与投影。均已有真实 API 样例，水墨另重绘一版来拉开差异。
3. **先欣赏，再对照。**默认大图，增加可键盘操作的滑杆对照；保留并排 / 原图视图，新增放大赏画及 Esc 返回。风格卡使用真实样例缩略图。
4. **作品可带走。**新增收藏展签 PNG，将成图、玩家题名、选择与场景编号排成一张卡；原作、成图和对照图仍可单独导出。
5. **收敛界面误导。**像素页隐藏 AI 媒介卡；取景明确为中轴全景；缺少结果时显示实际原图并禁用无效对照。手机作品页改为上下布局。

新意来自同一场景在不同物质媒介中的重塑，以及带个人选择的收藏展签；探索世界本身仍为像素风。本版不包含视频。

## 检查与边界

已完成单文件构建、12 种配置与任务依赖检查、三样例绑定、取景 / 风格隔离、迟到响应隔离；浏览器实际切换三种媒介、操作滑杆、放大赏画、输入题名并下载 1440×1580 收藏展签。390px 手机宽度下作品页无横向溢出。离线包校验与源码页面一致。

固定成品场景离线可看三张结果，自创场景需实际调用服务，不能复用样例冒充结果。图片可能改写人物、建筑细部和倒影；保留空间关系不等于逐像素复原。新结果暂存页面会话，需主动下载。只检查本次功能，不代表旧工程全面验收。

## 队友复用

风格集中在 src/art-styles.js；三种结果在 assets/samples.json 精确绑定同一场景，样例不得按主题词模糊匹配。新增导出 API 为 FusionArtwork.downloadPrint()。上级交互.md 已记录接口与分支适配方式。

本分支基于 v0.5 / WorldSpec v3。v0.6 已有 WorldSpec v4 与新场景绘制，复用时应迁移媒介提示与作品页能力，并适配其截图及场景字段，避免整文件覆盖。

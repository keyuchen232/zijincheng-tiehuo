# 队友如何接入 Image

## 下载哪一个

| 文件 | 可以做什么 | 额外环境 |
| --- | --- | --- |
| `*-offline.zip` / 离线试玩 ZIP | 探索、创作、查看三张样例、导出与导入图片 | 无 |
| `*-full.zip` / Image完整工程 ZIP | 上述能力，以及通过本机后端为新场景请求转绘 | Python、imagegen CLI、SDK、自己的图片服务认证 |
| GitHub Code → Download ZIP | 与完整工程 ZIP 同类，包含源码和本机后端 | 在线转绘仍需上述环境 |

完整包不会包含作者的密钥、账号配置、Python 安装程序或 imagegen 技能。当前后端仍借用 Codex 的 imagegen CLI，**只安装 Python 和填写 API Key 还不够**；如果队友没有这个 CLI，不能直接在线生成。

## 当前版本的配置与操作

1. 下载完整包并解压；不要只转发 index.html。
2. 准备 Python 3.11+。在解压目录安装依赖：

   ```sh
   python -m pip install -r requirements-ai.txt
   ```

3. 队友自己的 Codex 配置目录中需存在 `skills/.system/imagegen/scripts/image_gen.py`。默认配置目录为用户主目录下的 `.codex`，也可通过 CODEX_HOME 指定。此脚本不在本包中；没有时可先使用离线或外部导入流程。
4. 同一目录的 config.toml 需有选中的 model_provider，以及该服务商的 base_url、env_key；env_key 指向本机环境变量的名称，实际 Key 放在环境变量里。沿用已有配置，不要用别人的完整配置覆盖自己的文件。具体要求见 [图片工具说明](tools/image-api/README.md)。
5. 确认该服务商支持本版 gpt-image-2 图片编辑、medium 质量、1040×896 / 1280×720 尺寸。聊天接口可用不代表图片编辑可用。
6. 新开启动进程以继承环境变量。Windows 双击 `启动AI绘景.bat`；如果 Python 未被识别，设置 WANXIANG_PYTHON 为 python.exe 完整路径。也可在命令行运行 `python serve_ai.py`。
7. 在打开的 `http://127.0.0.1:8319/` 中进入自己的场景，按 P → AI 绘景 → 选取景与媒介 → 确认「本机图像服务已连接」→ 点击转绘。
8. 下载结果；结束时运行 `停止AI绘景.bat`，或在命令行用 Ctrl+C 停止。

不要继续使用原先双击 HTML 打开的 `file:` 页面。HTTP 与 file 是不同来源，存档不保证互通。服务显示已连接只代表本机依赖检测通过，不能保证远端额度与图片接口可用。

## 队友没有配置环境时

仍可离线玩 Demo，查看内嵌样例；或者在作品页导出当前原图和提示词，用自己的图生图工具生成，再回到相同取景与媒介导入结果。这样可以体验成图工作流，但不是页面内直接请求 Image API。

## 分享与计费

完整 ZIP 是可安装配置的本机工程包，不是已经部署的在线服务。127.0.0.1 是各自电脑，不能作为远程试玩链接。每人使用自己的认证；如将来希望队友点链接即可生成，需要另行部署带认证、额度限制的后端，密钥不能放进 HTML。

每次主动转绘可能计费，失败不自动重试。新生成/导入结果仅缓存在页面会话，关闭前下载。此完整包补齐的是分享与启动材料，尚未将图片调用从 Codex CLI 中独立出来。

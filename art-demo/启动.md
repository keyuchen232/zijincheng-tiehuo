# 启动说明

## 只想看 Demo

下载仓库 ZIP 或 Release 离线试玩包，**完整解压**后双击 `index.html`，也可运行 `启动离线试玩.bat`。无需安装环境。推荐 Chrome / Edge。

首页点「先看成品」→ 选择青绿绢绘 / 水墨留白 / 纸雕光境 → 欣赏成图、并排或滑杆对照 → 放大赏画 → 输入题名 → 下载成图或收藏展签。Esc 退出赏画，再按 Esc 返回探索。

三张结果只绑定固定成品场景。自行创作或选择「此刻所见」时没有预生成结果，需要下述在线流程，或者导出原图与提示词、外部转绘后导入。

## 给自己的场景生成 AI 画作（可选）

也可以下载 Release 的 `*-full.zip`（Image 完整工程包），无需 Git 克隆。先看 [Image接入-队友先读.md](Image接入-队友先读.md)：当前实现还依赖队友本机的 imagegen 技能 CLI，不只需要 Python 和 API Key。

1. 下载完整仓库，而非仅离线试玩包。按 [图片工具说明](tools/image-api/README.md) 配好 Python、依赖与自己的认证。
2. Windows 双击 `启动AI绘景.bat`，后台启动服务，并打开 `http://127.0.0.1:8319/`。
3. **在这个新打开的页面**探索/创作，按 P 打开作品页。原先 `file:` 页面的存档与此页面不保证互通。
4. 切到 AI 绘景模式，选择取景与媒介，确认显示「本机图像服务已连接」，点击转绘，等待完成。
5. 对照原图、下载成图或收藏展签。生成与导入结果暂存于当前会话，刷新前请下载。
6. 结束后双击 `停止AI绘景.bat`。

macOS / Linux 或命令行可执行 `python serve_ai.py`，手动打开上述地址；Ctrl+C 停止。

每次主动提交请求一张，可能产生 API 费用；失败无自动重试。自定义服务商须支持配置模型的图片编辑和本版尺寸，聊天接口可用不代表图片接口可用。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 只有源代码/网页文本 | 从 GitHub 下载 ZIP 并解压，不在 GitHub 文件预览里运行 |
| 作品页提示离线，按钮灰色 | `file:` 页面只能离线浏览；请用 AI 启动脚本打开 8319 页面 |
| HTTP 页面仍提示离线 | 检查 Python、图片 CLI、SDK 和环境变量；重开启动脚本以继承新变量 |
| 提示已连接但生成失败 | 检查服务商图片模型、额度、网络和尺寸支持；先确认任务状态再重试 |
| 换风格或取景后只有原图 | 新输入没有匹配结果，需要生成或导入对应画作 |
| 队友打不开我的 localhost 链接 | 这个地址属于各自电脑；发下载链接/试玩包，由队友自己启动 |

Node.js 仅用于重新构建，不影响试玩。Python 仅用于在线服务；没有图片认证也可以启动服务浏览 Demo。

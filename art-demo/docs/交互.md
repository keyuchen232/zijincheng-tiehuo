# 交互与复用 · v0.5-art.1

## 独立交付工作流

`src/ + assets/ + vendor/` → `node build.js` → 完整 `index.html` → `node verify.cjs` → `node tools/package.cjs` → 离线 ZIP。

页面内嵌脚本、样式、原图和三张样例，不使用 CDN。队友下载、完整解压、双击 HTML 即可试玩；不要求安装开发环境。在线图片生成是可选的本机后端能力，不能混称为离线能力。

打包脚本同时生成 `*-offline.zip` 与 `*-full.zip`。离线包只包含页面与简要说明；完整包按白名单包含后端、启动脚本、图片桥接、依赖清单和源码。完整包仍不含 Python 安装程序、imagegen 技能 CLI 或认证，不能宣传为零配置在线版；具体接入见根目录 Image接入-队友先读.md。

构建依赖全部在本仓库，vendor 仅保留所需的雅典引擎/绘制与紫禁城绘制代码。更新 vendor 后必须重建并检查适配。

## 场景规格与试玩进度分离

WorldSpec v3 保存布局、互动节点、任务依赖与文化引用，并保持不可变；RuntimeProgress v1 保存任务状态、玩家选择与作品选项。恢复进度不得向规格里塞 flags。存档键为 `wanxiang.fusion.explore.art1`，底层引擎键为 `wanxiang.fusion.explore.engine.art1`。

本版不能覆盖其他分支的 v4 场景实现。复用时迁移作品页与提示词能力，再适配对方的截图尺寸、场景字段和身份计算。

## 成图接口与结果绑定

- `src/art-styles.js`：媒介与提示词单一来源，style 为 `jade`、`ink`、`paper`。
- `FusionArtwork.prepareImageRequest()`：导出 `wanxiang.image-edit` v2 请求及 identityKey。
- 中轴取景原图/输出为 1040×896；此刻所见原图为 640×360，输出 1280×720。
- `FusionArtwork.setImageAdapter(adapter)`：接入异步转绘实现；`loadResult(blob)`：导入结果；`downloadPrint()`：收藏展签。
- `GET /api/status` 返回可用状态和当前会话 token；`POST /api/artwork/render` 接收请求与原图，返回 PNG。仅同源本机页面调用，API 密钥始终留在后端。

样例由 `assets/samples.json` 的 identityKey 精确绑定场景、取景、选择及风格，并记录原图/结果 SHA256。不能按主题词近似匹配，也不能将旧结果套给新输入。异步结果返回时应核对当前输入，避免覆盖切换后的作品。

规格与选项可以存档；新图片缓存只在页面会话，须主动下载。分享作品可导出成图、原图对照或带题名与选择的收藏展签。

## 实际生成操作

AI 启动脚本 → 新打开的 8319 页面 → 进入自己的场景 → P → AI 绘景 → 选取景/媒介 → 确认服务已连接 → 主动转绘 → 对照/下载 → 停止本机服务。

`file:` 与 `http:` 为不同来源，存档不保证互通。三张离线样例不是新场景的生成结果；更换取景/媒介后只见原图属正常隔离。每次提交可能计费，失败不自动重试。

外部绘图流程：在同一作品输入下导出原图与提示词 → 外部图生图 → 回到相同取景与媒介导入 → 人工核对布局与内容 → 下载。队友需使用自己的认证，不能共享密钥或本机 localhost 地址。

# 素材与生成说明

本仓库是黑客松项目「万象灵境」的成图演示快照。

- `src/` 来自本项目融合探索 v0.5 成图优化分支。
- `vendor/athens/` 来自项目内 `athens-city-v2.0.0` 的必要引擎、世界与绘制代码。
- `vendor/forbidden-city/` 来自项目内 `zijincheng-tiehuo-v1.0.0/forbidden-city` 的建筑绘制代码；build.js 将其隔离到 FusionPalace 命名空间。
- `assets/source.png` 为实际游戏场景截图；`result-*.png` 为该截图的 AI 图生图结果，模型记录为 gpt-image-2，quality=medium，1040×896。水墨最终版经历一次重绘。
- `prompt-*.txt` 保存最终提示词，`samples.json` 保存场景绑定与原图/结果哈希。`预览/` 为本版作品截图与对照。

本次整理未给原型或第三方素材补授开源许可证。公开可见不等于所有素材均可任意商用；团队后续应核实贡献者授权及素材许可，再决定正式许可证。生成画作可能改变建筑细节，不作为精确复原或文化史依据。

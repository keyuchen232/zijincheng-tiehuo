# 门院成序

适用场景：palace。这是项目内的玩家创作技能；不会自动安装到队友的 AI 工具。

## 空间规则

门—院—殿递进；主院开敞、两翼呼应，保留侧廊回游和可穿过的门洞。

## 编译与交互

对称主院、两道门庭、开敞前院与两翼建筑；使用真实门洞碰撞。 使用 `skills/catalog.json` 中的同名 ID，通过 `CreativePlan.skills` 选择。必选技能不能从对应场景移除。只返回方案 JSON，不生成可执行代码或任意坐标。主骨架固定由用户选择；`spatialIntent` 控制聚合/错落，`gardenSide` 控制侧庭朝向；其余结构由编译器保障。

## 出处与转译边界

参考：https://www.dpm.org.cn/explore/buildings.html

以故宫门院组织为参照，非实测复原；不把等级制度当作玩家价值判断。

## 复用

让 AI 阅读本文件、`../catalog.json`和项目 `交互.md` 的 v0.7 契约。将 ID 加入请求的 `skills` 数组；不要仅把规则追加到描述中。输出后运行项目验证，再由浏览器检视空间表达。

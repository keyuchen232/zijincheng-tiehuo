# 柱间有节

适用场景：acropolis。这是项目内的玩家创作技能；不会自动安装到队友的 AI 工具。

## 空间规则

以重复柱列和空间间距建立可感知的节奏；允许观者用行走改变节奏方向。

## 编译与交互

三块空间声石按次序踩亮，完成后柱廊与地面流光同步；未选时使用自由声石。 使用 `skills/catalog.json` 中的同名 ID，通过 `CreativePlan.skills` 选择。必选技能不能从对应场景移除。只返回方案 JSON，不生成可执行代码或任意坐标。主骨架固定由用户选择；`spatialIntent` 控制聚合/错落，`gardenSide` 控制侧庭朝向；其余结构由编译器保障。

## 出处与转译边界

参考：https://www.ysma.gr/en/monuments/parthenon/

柱列重复有建筑参照；三音行走游戏是现代转译，不是古希腊仪式或历史音乐复原。

## 复用

让 AI 阅读本文件、`../catalog.json`和项目 `交互.md` 的 v0.7 契约。将 ID 加入请求的 `skills` 数组；不要仅把规则追加到描述中。输出后运行项目验证，再由浏览器检视空间表达。

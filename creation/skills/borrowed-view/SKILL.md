# 框景与借见

适用场景：故宫、雅典及融合场景。这是项目内的玩家创作技能；不会自动安装到队友的 AI 工具。

## 空间规则

区分近处框口、侧庭水树与远处建筑，用遮露和取景方向建立层次。

## 编译与交互

侧庭出现取景窗；转动取景方向，使远景轮廓落入窗心；未选时为开放观景台。 使用 `skills/catalog.json` 中的同名 ID，通过 `CreativePlan.skills` 选择。必选技能不能从对应场景移除。只返回方案 JSON，不生成可执行代码或任意坐标。主骨架固定由用户选择；`spatialIntent` 控制聚合/错落，`gardenSide` 控制侧庭朝向；其余结构由编译器保障。

## 出处与转译边界

参考：https://zh.wikisource.org/wiki/園冶

借景是中国园林的另一个参照，不能等同故宫整体布局；《园冶》仅作概念阅读线索，当前旋转取景小游戏为虚构。

## 复用

让 AI 阅读本文件、`../catalog.json`和项目 `交互.md` 的 v0.7 契约。将 ID 加入请求的 `skills` 数组；不要仅把规则追加到描述中。输出后运行项目验证，再由浏览器检视空间表达。

# 海报动态主菜单验证

本次使用用户提供的本地海报（965×1630），复制至 assets/title/poster-original.png；无图片生成 API。属于海报原图的动态编排，并非新绘人物插画。

正常入口：http://127.0.0.1:8123/ 。新增 css/title-poster.css 与 js/title-poster.js，由 index.html 引用。js/main.js 在图片成功加载后停止绘制被遮住的原标题画布；图片失败时继续原程序画面并显示。

复现：启动 `node serve.js`（已有服务则复用），执行 `node tools/check-title-poster.mjs`。环境 Windows、Node v24.15.0、Edge headless，浏览器启动可能需要沙箱外权限。检查结果与截图写入 artifacts/title-poster/。

检查范围：1440×900、1920×1080、390×844、844×390 图片载入、五入口矩形与中心点命中、横向溢出；暂停动画状态、系统 reduce 的动画数；鼠标点击主入口进入午门。只实测主入口，其他玩法未逐一通关。系统 reduce 的 CSS 保证动画禁用；按钮偏好文案同步不作为验证通过结论。

独立上下文审查指出手机横屏提示遮挡、暂停键盘事件冒泡、缺图降级、极短屏滚动和独立离线单文件资源限制。前四项已处理；后续合并修复已解决 web.html 冲突并重建离线单文件，详见 docs/changes/pixel-mentor-merge.md。本记录的标题页检查针对 HTTP 入口，不能代替离线海报资源完整性验收。极短屏滚动及缺图恢复路径仅静态审查，未列为运行验证通过项。

未进行模型视觉验收：当前模型不能读图片。object-fit:contain 保证图片元素不裁源图，不能据此声称海报角色在所有布局下无遮挡。截图及 GIF 供用户最终验收。动画为整图轻微位移缩放与环境装饰，不包括角色骨骼动画。

- `index.html` 标题页有 `#btn-start`（北京线）、`#btn-continue`（只认北京线）、`#btn-fusion`（万象灵境）、`#btn-athens`（雅典·卫城，一整个第二游戏）。

## 2. 本次冲刺的 Definition of Done

演示时按这个顺序走一遍不卡壳，就算完成：

1. 打开页面 → **标题只有一个「进入万象灵境」**（有存档时多一个「继续」）。
2. 午门：狄奥提玛开场 → 发放第一张来源卡。
3. 太和殿东庑 / 乾清宫西庑：**点击即取**两份档案（榫卯、大理石小游戏降级为可选彩蛋，不走必要路径）。
4. 太和殿月台：**两次点击**把被卫城投影打乱的说明标签归位，30–45 秒，点错能重试。
5. 乾清宫前修复台：3 条来源判断，答错给「不声称什么」的边界解释。
6. 御花园创作终端：选组件 + 输入一句中文 → **≤8 秒**返回蓝图 → 预览 → 每件组件标出来源。
7. 进入自造关卡：两线索 → 配对 → 打开出口（1–3 分钟）。
8. 神武门点亮 → 结局 → 分享卡（可截图）。
9. 断网／模型挂 → 走兜底蓝图，**演示不中断**。
10. `grep -rn "tiehua" js/ index.html` 在主线代码里为 0（`legacy/` 与 `docs/` 除外）。

## 3. 四个接口契约（H+2 之前冻结，谁先冻谁先动工）

四个人并行不打架的前提：**先把边界定死**。下面四块，各自只有一个 owner。

**① 关卡蓝图（C 所有，文件 `js/blueprint.js`）**

```js
{
  schemaVersion: 1,
  templateId: 'gugong_acropolis_preserve_palace' | 'gugong_acropolis_preserve_acropolis',
  placements: [{ slot: 'n'|'s'|'e'|'w'|'c', componentId: 'gugong_hall', tag: 'gugong'|'acropolis'|'personal'|'kept' }],
  gameplay: { kind: 'evidence_pair', clueIds: ['clue_a','clue_b'], answerPairId: 'pair_banquet' },
  sourceCardIds: ['sc_banquet', 'sc_kore'],
  preservedRuleIds: ['gugong_axis_relation'],
  generationMode: 'ai' | 'fallback',
  narrative: { title, oneLine, why }
}
```

导出：`G.blueprint.blank(templateId)`、`G.blueprint.validate(obj) -> {ok, errors}`、`G.blueprint.fallback(prompt, cards)`。

**② 生成接口（D 所有）**

`POST /api/generate` ← `{ prompt, templateId?, allowedCardIds[], slots[] }`
→ `200 { ok:true, blueprint, model, ms, fallback:false }`
→ `400 { ok:false, errors:[...] }`（前端据此走 fallback，不弹错误框）

**③ 来源卡数据（B 所有，文件 `js/source-cards.js`）**

```js
G.sourceCards = [{ id:'sc_banquet', kind:'pair'|'boundary'|'map',
  title, cn:{ item, date, where }, gr:{ item, date, where },
  layer:'功能可比'|'空间观念对照'|'间接传播边界',
  claim:'可以说什么', notClaim:'不声称什么', refs:[...] }]
```
id 命名规则 `sc_*`，**一处定义，A/C/D 只读**。

**④ 组件美术（A 所有，`js/art-greek.js` + `js/art.js`）**

`G.componentArt[componentId](ctx, x, y, scale, tag)` —— 沙盘（A）与创作预览（C）共用同一套画法，避免两边画得不像。

### 协作规则（比排期更重要）

1. **文件所有权**：上表「主要交付物」里的文件只有 owner 能提交，别人改一律走 issue。`index.html`、`styles.css` 是公共文件，谁改谁先说一声。
2. **契约优先**：H+2 前把 §3 四个接口贴到群里定稿，之后只加字段不改形状。
3. **每天两次同步**（开工／收工各 10 分钟），只答三问：昨天交付了什么 / 今天交付什么 / 卡在谁身上。
4. **互审**：A↔C（场景与面板的边界）、B↔D（卡数据与 prompt 白名单的边界）——这两对最容易对不上。
5. **改完立刻验证**：`node tools/test.mjs`（断言要同步改成新入口）+ `node tools/build-web.mjs`（演示用单文件版）。
6. **不删只挪**：所有废案 `git mv` 进 `legacy/`，保留可追溯，答辩时还能说「我们做过什么、为什么砍」。

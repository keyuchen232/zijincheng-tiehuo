# 文案接手文档 · 把游戏改成「文案可替换」的设计

> **⚠️ 本文是历史方案稿。真正落地的接口见 [模块接口.md](模块接口.md)。**
> 两者有两处不同，以 `模块接口.md` 为准：
> 1. 文件叫 `js/str.js`、API 叫 **`G.str`**（不能叫 `G.text` —— `G.text` 在 `js/core.js:690` 已经是画布绘字函数，重名会毁掉所有文字渲染）。
> 2. 新增了 `js/mod.js` / `js/stage.js` / `js/cut.js`，文案表只是地基四件套之一。
> 下文保留下来，是因为它的**迁移步骤和 lint 规则**仍然有用。

> 给负责脚本的队友。目标：**改一句话不用改 JS，改完刷新就生效。**
> 本文描述的是**改造顺序**；改造完成后再导入 `data/script.json`（剧情 owner 维护）。
> 预计工作量：**约 5 小时**，可拆成 4 次独立提交，每一步都能单独回滚。

## 0. 一句话方案

现在文案硬编码在 8 个 JS 文件里。改成：**`data/script.json` 是唯一真源 → `js/str.js` 加载并暴露 `G.str` → 所有场景只查 key，不写字面量。**

```
data/script.json   ← 人编辑（剧情 owner）
data/script.js     ← 构建生成：window.WXL_SCRIPT = {...}（给 file:// 和单文件版兜底）
js/str.js         ← 加载器 + 查表 API
tools/lint-text.mjs← 双向校验（JSON ↔ 代码）
tools/build-web.mjs← 把 JSON 内联进 web.html
```

## 2. 加载顺序与 `G.str` API

`js/str.js` 放在 `core.js` 之后、`main.js` 之前加载（`index.html` 的 `<script>` 顺序里插一行）。它自己暴露一个就绪 Promise：

```js
G.str.ready.then(() => G.boot());
```

API（八个方法够用）：

| 方法 | 用途 |
|---|---|
| `G.str.get(key, vars)` | 取字符串，`{name}` 占位符用 `vars` 替换 |
| `G.str.seg(key)` | 取对白数组（`[{who,text}]`），给对话框 / 字卡用 |
| `G.str.has(key)` | 是否存在 |
| `G.str.who(id)` | 取角色（名字、颜色），缺失回退到 `system` |
| `G.str.all(section)` | 取整个数组（`sourceCards` / `codex` / `objects`）|
| `G.str.node(id)` | 取节点信息（name/sub/objective/enter/hint）|
| `G.str.puzzle(id)` | 取关卡数据（题干/选项/判定/台词）|
| `G.str.missing()` | 返回本次运行所有缺失的 key（开发用）|

**缺失 key 的行为**：返回 `⟪key⟫` 并 `console.warn` 一次。**永远不抛异常、永远不空白**——这样少一条文案不会让演示白屏，而且一眼能看出漏了哪个。

## 3. 加载器的三种运行环境（这是最容易翻车的地方）

| 环境 | 怎么打开 | `fetch('data/script.json')` | 方案 |
|---|---|---|---|
| 正常开发 | `node serve.js` → `http://127.0.0.1:8123/` | 可以 | 直接 fetch |
| 双击打开 | `file:///.../index.html` | **被 CORS 拦住** | 用 `data/script.js` 兜底 |
| 单文件演示版 | `web.html`（`tools/build-web.mjs` 生成） | **没有相对路径可 fetch** | 构建时内联 |

所以加载器的顺序必须是：

```js
// 1) 构建产物 / 兜底脚本
if (window.WXL_SCRIPT) return window.WXL_SCRIPT;
// 2) 正常 fetch
const res = await fetch('./data/script.json', { cache: 'no-store' });
// 3) 全挂 → 空对象 + 大量 ⟪key⟫，游戏仍能跑
```

`tools/build-web.mjs` 里加两步：读 `data/script.json` → 生成 `data/script.js`（`window.WXL_SCRIPT = <json>;`）→ 把 `script.js` 也内联进 `web.html`（它现在已经在内联各 `js/*.js`，加一个文件即可）。

## 4. 迁移四步（每步一次独立提交）

### Step 1 · 只增不改（≈0.5 h）
- 新增 `js/str.js`、`data/script.js`（由构建生成）；
- `index.html` 加一行 `<script src="js/str.js"></script>`；
- 新增 `tools/lint-text.mjs`；
- **不动任何现有场景**，此时游戏行为完全不变。

验收：`node tools/lint-text.mjs` 通过；控制台打印 `[text] loaded N keys`。

### Step 2 · 迁 `fusion.js`（≈2 h，最大头）
把四个函数改成查表，**函数签名一律不变**，改动量最小：

```js
// 改前
introLines() { return [ {who:'diotima', text:'抱歉。我把卫城…'}, ... ]; }
// 改后
introLines() { return G.str.seg('nodes.wumen.enter'); }
```

- `introLines()` → `nodes.wumen.enter`
- `evelynLines()` → `nodes.<当前节点>.enter`（原来是分支对白，按节点拆）
- `useTerminal()` 的 4 张字卡 → `puzzles.taihe.labels.success`（或新建 `cinema.*`）
- `enterPortal()` 的 3 张字卡 → `ending.lines`
- 所有 `G.ui.prompt('…')` → `G.str.get('ui.toast.…')`

### Step 3 · 迁 `source-quiz.js` + 图鉴 + 标题（≈1.5 h）
- 三题内容 → `puzzles['repair_bench.evidence']`（`clues[].text / explain` 直接对应题干与解释）；
- `G.CODEX_DATA` → `G.str.all('codex')`，字段从 `{id,title,body}` 映射到 `{id,name,desc}`；
- `index.html` 的标题/按钮 → 启动时用 `G.str.get('ui.title.logo')` 回填 `textContent`。

### Step 4 · 迁小游戏与旧线归档（≈1 h）
- `archive-game.js` 四行标题 → `ui.*`；
- `difficulty.js` 三个名字 → `ui.difficulty.*`；
- `gugong.js / beijing.js / home.js / minigame*.js / entry.js / puzzle.js` 整体 `git mv legacy/js/`，`index.html` 去掉对应 `<script>`；
- 重跑 `node tools/test.mjs`（断言要同步改成新入口）。

## 5. 校验脚本（`tools/lint-text.mjs`）

不写这个脚本，三天后一定会出现"某句台词是 `⟪undefined⟫`"。

必须检查的八项：

1. `JSON.parse` 通过；
2. 每段对白的 `who` 都在 `characters` 里；
3. `sourceCards[].id` 全局唯一，且 `puzzles` 里引用的卡 id 都存在；
4. `puzzles.*.outcome` 的 key 与 `options[].id` 一一对应（关 1 的 `A/B/C`）；
5. `puzzles['qianqing.loadtest'].outcome` 的 key 与 `materials[].id`、`methods[].id` 一一对应（6 种组合都要有）；
6. 段落内 `{who,text}` 结构完整，`text` 非空；
7. 长度告警：字卡单行 ≤ 28 字、对话框单行 ≤ 60 字（只警告）；
8. 反查：`js/` 里 `G.str.get('x')` 用到的 key 都存在；JSON 里从未被引用的 key 只警告。

CI 里加一步 `node tools/lint-text.mjs`，挂在 `tools/test.mjs` 之前。

## 6. 给文案 owner 的编辑规则（贴在 `data/script.json` 顶部）

1. 只改 `text` / `desc` / `claim` / `notClaim` 字段，**不要改 key**；要改 key 先同步代码。
2. 一个 key 一处定义。宁可重复写，不要跨文件引用（改漏比重复更贵）。
3. 不用 `\n` 排版，换行由 UI 决定；需要停顿用 `pause` 字段。
4. 不用 HTML 标签，`<b>` 之类的会被当字面量显示。
5. 数字/名字用 `{name}` 占位，不要拼接句子。
6. 中文引号统一用「」，避免和 JSON 的 `"` 混淆。
7. 不放条件判断（"如果玩家选错则…"），分支属于代码，文案只写每个分支里说的话。
8. 史实不确定的条目标 `needsVerify: true`，卡面会显示"待核对"，不参与结论。

## 7. 三个必须一起改的实现约束（否则新剧情跑不起来）

这三条不是文案问题，是**新关卡的结构要求**，改的时候顺手做掉：

1. **关 1 的三选一**：`puzzles['wumen.registration'].outcome` 是 `{A,B,C}` 对象，判定要按 id 取，不能靠数组下标（将来加选项会错位）。
2. **关 3 的六种组合**：`outcome.<material>.<method>.ok` 是布尔值，**两种材料各至少成功一次才通关**；且"石柱 + 榫卯"必须被尝试过一次（塌一次）才算理解——否则这一关的教学点拿不到。
3. **关 5 的违规**：`puzzles['creator.review'].plan.placements[1].tag` 故意写成 `gugong`（女像柱却标成故宫参考）。接入 AI 之后，**兜底蓝图也必须保留这一处错误**，否则离线演示时关 5 失效。

## 9. 附：可抄的最小实现

### `js/str.js`（约 60 行）

```js
(function () {
  'use strict';
  const G = window.G || (window.G = {});
  const MISSING = new Set();

  let data = null;

  function resolve(obj, path) {
    return path.split('.').reduce((o, k) => (o == null ? undefined : o[k]), obj);
  }

  function warn(key) {
    if (MISSING.has(key)) return;
    MISSING.add(key);
    console.warn('[text] missing key:', key);
  }

  function get(key, vars) {
    const v = resolve(data, key);
    if (typeof v !== 'string') { warn(key); return '⟪' + key + '⟫'; }
    if (!vars) return v;
    return v.replace(/\{(\w+)\}/g, (m, k) => (vars[k] != null ? vars[k] : m));
  }

  function seg(key) {
    const v = resolve(data, key);
    if (!Array.isArray(v)) { warn(key); return []; }
    return v;
  }

  const text = {
    ready: null,
    get,
    seg,
    has: (k) => resolve(data, k) !== undefined,
    who: (id) => (data.characters && data.characters[id]) || data.characters.system,
    all: (s) => (Array.isArray(data[s]) ? data[s] : []),
    node: (id) => (data.nodes && data.nodes[id]) || {},
    puzzle: (id) => (data.puzzles && data.puzzles[id]) || {},
    missing: () => Array.from(MISSING)
  };

  async function load() {
    if (window.WXL_SCRIPT) { data = window.WXL_SCRIPT; return; }
    try {
      const res = await fetch('./data/script.json', { cache: 'no-store' });
      data = await res.json();
    } catch (e) {
      console.error('[text] load failed, running with empty script', e);
      data = { characters: { system: { name: '系统' } }, nodes: {}, puzzles: {}, ui: {} };
    }
  }

  text.ready = load().then(() => {
    console.log('[str] loaded', Object.keys(data).length, 'sections');
    return data;
  });

  G.str = text;
})();
```

### `tools/lint-text.mjs`（骨架）

```js
import { readFileSync } from 'node:fs';
const S = JSON.parse(readFileSync('data/script.json', 'utf8'));
const err = [], warns = [];
const chars = Object.keys(S.characters || {});

function walkSegs(obj, path = '') {
  if (Array.isArray(obj)) {
    obj.forEach((row, i) => {
      if (row && typeof row === 'object' && 'who' in row) {
        if (!chars.includes(row.who)) err.push(`${path}[${i}] unknown who: ${row.who}`);
        if (!row.text) err.push(`${path}[${i}] empty text`);
        if (row.text && row.text.length > 60) warns.push(`${path}[${i}] too long (${row.text.length})`);
      } else if (row && typeof row === 'object') walkSegs(row, `${path}[${i}]`);
    });
  } else if (obj && typeof obj === 'object') {
    for (const [k, v] of Object.entries(obj)) walkSegs(v, path ? `${path}.${k}` : k);
  }
}

walkSegs(S);
const reg = S.puzzles?.['wumen.registration'];
if (reg) {
  const ids = reg.options.map((o) => o.id).join(',');
  const out = Object.keys(reg.outcome).join(',');
  if (ids !== out) err.push(`wumen.registration: options(${ids}) != outcome(${out})`);
}
const cardIds = new Set((S.sourceCards || []).map((c) => c.id));
for (const c of S.puzzles?.['repair_bench.evidence']?.clues || []) {
  if (c.answerCard && !cardIds.has(c.answerCard)) err.push(`clue ${c.id} -> unknown card ${c.answerCard}`);
}
console.log(err.length ? `✗ ${err.length} errors` : '✓ script ok', warns.length ? `(${warns.length} warnings)` : '');
err.forEach((e) => console.log('  ✗', e));
warns.slice(0, 10).forEach((w) => console.log('  !', w));
process.exit(err.length ? 1 : 0);
```

## 10. 如果只有两小时

只做这三件事，收益最大：

1. `js/str.js` + `data/script.js`（30 min）——先让它能加载；
2. 迁 `fusion.js` 的对白（60 min）——这是 70% 的改动量；
3. `tools/lint-text.mjs` 的 `who` / 空文本 / 卡 id 三项检查（30 min）——防止演示当天出现 `⟪undefined⟫`。

标题页、图鉴、小游戏标题可以暂时继续硬编码，不影响文案替换的主链路。

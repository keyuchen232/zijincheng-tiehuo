# 万象灵境 · 通关攻略（给第一次玩的人）

> 一句话：**这不是打怪游戏。** 六关里你要做的事只有三种——走过去、看一眼、选一个。全部关卡加起来 8–12 分钟，没有会输的结局，选错可以重来。

---

## 0. 三十秒上手

| 你要做的 | 怎么做 |
| --- | --- |
| 走 | `W A S D` 或方向键（`Shift` 快走） |
| 互动 | 走到**发光的地面标记**上，按 `E`（屏幕下方会出现提示条） |
| 读对话 | 按 `E` 或点一下 → 下一句；空格可以跳过打字 |
| 选选项 | **用鼠标点**对话框里的按钮（触屏直接点） |
| 跳过过场 | 按 `空格`（按一次就跳） |
| 忘了要干什么 | 看屏幕左上角的**当前目标**；按 `M` 看导览图 |
| 卡住了 | `Esc` 暂停 → 重置进度；或浏览器控制台执行 `localStorage.removeItem('zijincheng.tiehuo.save.v1'); location.reload()` |

**开始玩：**

```bash
node serve.js            # 然后浏览器打开 http://127.0.0.1:8123/
```

首屏是黑屏倒计时（按空格可跳）→ 标题页点「进入万象灵境」→ 从午门开始。

## 1. 六关怎么过（按顺序，附答案）

### 关 1 · 午门｜原点之争

- **要做什么**：两套坐标系叠在一起，网格错位。系统问你"以哪里为原点"。
- **怎么做**：走进午门内广场，踩上发光点按 `E`，三选一。
- ✅ **选「午门门洞中心」（A）**。
  - 选 B（太和殿月台中心）或 C（投影自身中心）：两套网格会被一起拖走，地面裂缝、门钉错位，**错误可以重来**。
- 广场上还有两个「看一眼」点（网格、门），不是必做，但看完更明白在争什么。
- 台词要点：*"两套东西出现在同一块地上，本身不算错。错的是——有人替它们写了不成立的关系。"*

### 关 2 · 太和殿月台｜说明牌归位

- **要做什么**：三块说明牌贴错了地方，把它们放到对的位置。
- **怎么做**：月台上按 `E`，系统逐块问你「挪」还是「留在原地」。
- 答案（顺序固定）：

| 牌 | 该怎么做 |
| --- | --- |
| 帕特农东山墙 | **挪到「属于它的位置」** |
| 伊瑞克提翁女像柱廊 | **挪** |
| 故宫太和殿月台 | **留在原地不动** ← 这关的重点：不是所有东西都要搬走 |

- 之后还会问你一次「这段空间关系要写进你的造境规则吗？」——**三个选项都能过**，随你（保留 / 记下待核 / 不要）。这一步是让你**主动做决定**，没有标准答案。
- 台阶、栏杆、档案、匾额各有「看一眼」点，可以边走边看；月台前还有三层「分层」点（石 / 像 / 牌），点一下开关一层叠印。

### 关 3 · 乾清宫｜承重实验

- **要做什么**：两种柱子 × 三种接法，试出哪种接得住。
- **怎么做**：走到殿前发光点按 `E`，先选材料，再选工法，点「加载」看结果。
- 答案：

| 材料 | 正确工法 | 为什么 |
| --- | --- | --- |
| 石柱（女像柱） | **铅灌铁销** | 石头不咬榫，靠铁销加铅灌固定 |
| 木柱（故宫） | **榫卯** | 木头会胀缩，榫卯越用越紧 |

- 选错会塌，塌了再选，不影响进度。
- 台词要点：*"这个院子里的等级，我不打算替你辩护。我要你带走的是它的做法。"*

### 关 4 · 修复台｜来源判断 + 结尾反转（本作核心）

**第一段：把线索接到来源卡上**

- **要做什么**：桌上四张线索卡，接给对应的来源卡，并且说明你比的是"哪个层面"。
- 做法：按 `E` 打开，先选线索，再选来源卡，最后选层面（功能可比 / 空间观念对照 / 间接传播边界）。
- 答案：

| 线索 | 接哪张来源卡 | 层面 |
| --- | --- | --- |
| 山墙构图 | 序列与构图（sc_sequence） | 空间观念对照 |
| 宴饮图 | 宴饮与礼仪（sc_banquet） | 功能可比 |
| 柱础纹样 | 边界与限度（sc_boundary） | 间接传播边界 |
| **女像柱柱础纹样** | **留白：不连，盖「未成立」** | — |

> 最后那条是**诱饵**：看着像，证据不足。硬连会被打回，选「留白」才对。这一步教的是"**克制**也是考据"。

**第二段：反转（务必体验）**

- 线索接完后，修复台上会**多出一个可点的地方**（R-07）。
- 系统推送：`R-07 待处置 · 检出外来机械构件 · 判定：错误混入 · 建议：移除后恢复本土形制。`
- 这就是故宫藏品**铜镀金珐琅转花活动人物钟**（清乾隆，文物号 故00183132）：西洋的塔轮、发条、透明珐琅，加上广州工匠自己加的**水法、转花、跑人、乐箱**。
- ✅ **选 B「改判：有据可查的历史融合，保留全件与完整说明」**。
  - 选 A（拆掉外来件）或 C（删掉外来说明）都会被打回：前者抹去交流，后者删证据。
- 台词：*"我们要修复的是错误，不是抹去交流。今天珍惜的传统里，也有前人曾经大胆的创造。"*

### 关 5 · 御花园｜审自己的方案

- **要做什么**：AI 给了你一份造境方案，你要审出里面的问题。
- 四步（顺序固定）：

| 问题 | 答案 |
| --- | --- |
| 保留哪条规则？ | 两条都能选，**随便选**（选「故宫中轴」走一条线，选「卫城正面」走另一条，结论一样） |
| 哪一件的来源标签写错了？ | **标着「故宫」的那件女像柱**（它其实是卫城的） |
| 属于哪类违规？ | **声称了不存在的传承** |
| 怎么改？ | **把标签改成它真正的出处**（不是删掉它！） |

- 台词：*"留住它。别改掉它，改掉来源就行。"*
- 这一关的规则面板写着：**不打分：不看风格占比，也不看文化纯度。**

### 关 6 · 神武门｜出门之前

- **要做什么**：门框暗着，需要三样东西齐了才亮：签过字的方案、看全的线索、说得清的三句话。
- 做法：
  1. 左侧和右侧各有一处**线索点**，先去看（不看会被直接拒绝："别凭印象"）。
     - 线索一：檐下斗拱被标成「山花」
     - 线索二：柱廊第六位少女脚下没有基座
  2. 回到门中央按 `E`，配对问：✅ **选「咬得上」**（一处标签错位、一处少了基座，是同一套错误的两种表现）。
  3. 门亮了，最后三问：**我借鉴了什么 / 我保留了什么 / 我新造了什么**。选例句或选「老实说：我还没想好」**都算过**——说清楚就行，不打分。
- 之后播放结局：灯一盏盏亮到景山，你的每一条方案旁边都写着它从哪儿来。
- 结尾主题句：**"AI 让创作可以天马行空；对传统的理解与敬畏，让想象有值得延续的根。"**

## 2. 最短路线（约 6 分钟，赶时间就照这个）

```
黑屏倒计时（空格跳） → 标题页「进入万象灵境」
→ 午门：踩点 E → 选「午门门洞中心」
→ 太和殿：E → 挪 / 挪 / 留 → 随便选保留项
→ 乾清宫：E → 石柱+铅灌铁销 → 木柱+榫卯
→ 修复台：E → 三条线索接线（山墙→序列、宴饮→功能、柱础→边界）+ 第四条留白
          → R-07 → 选 B「改判：历史融合」
→ 御花园：E → 随便选规则 → 指认「标着故宫的女像柱」→「声称了不存在的传承」→「改成它真正的出处」
→ 神武门：先去左右两处线索点（E）→ 回来 E →「咬得上」→ 三问随便选 → 结局
```

**唯一"必须选对"的只有两处**：关 1 的原点（A）、关 4 反转的判定（B）。其余选错都能重来，或者本来就允许自由选择。

## 3. 演示（答辩/路演 3 分钟版）

1. **开场 15 秒**：黑屏倒计时 → 空格跳过 → 午门全景（两套网格错位、帕特农柱廊叠在门后）。
2. **关 1（30 秒）**：故意选 C，让观众看见"两套网格一起被拖走"；再重来选 A。
3. **关 2（40 秒）**：只演第三次问答——"故宫太和殿月台：留在原地"。点明：不同文化出现在同一空间，本身不是错误。
4. **关 4（60 秒，高潮）**：把三条线索接对 → 让观众看 R-07 的系统推送 → 选 B → 收束对白。
5. **关 5–6（35 秒）**：指认错误标签 → 三句话（借鉴 / 保留 / 新造）→ 结局灯亮。

用深链省时间：`http://127.0.0.1:8123/?map=repair_bench` 直接进关 4；`/?map=wumen` 直接进关 1（跳过开场）。

## 4. 常见疑问

- **会不会输？** 不会。答错只是被打回重选，进度不丢。
- **要记住史料吗？** 不用。所有"正确答案"都能在屏幕上的线索里找到，游戏考的是**判断**，不是背诵。
- **为什么有些点没有反应？** 有的是"看一眼"（只出文字），有的是必须先完成前置（比如关 4 的反转点、关 6 的门）。
- **"留白"是什么意思？** 证据不够就不连。这是刻意设计的正确选项。
- **地图会不会很大？** 已经改小了：现在每关从出生点走到最远的交互点大约 3–5 秒，下方只留 40px 余量，不会再有"走半天什么都没有"的空场。

# PPT 大纲（≤15 页，匿名；每页一句话）

1. 封面：项目名 + 一句话定位（不写成员信息）
   > 一座会跟你对答案的北京中轴线
2. 痛点：文化类内容"看得见、用不上"——知识在展板里，不在人身上
3. 我们的答案：把文化做成三层可操作的东西
   - 空间（走出来的礼制次序）
   - 技艺（榫卯、打铁花、日晷，手上过一遍）
   - 证据（来源校准：什么能比较、什么不能编）
4. 产品形态：像素探索 + 三个可玩小游戏 + 考据台 + 转绘画册
5. Demo 1：北京中轴线 → 午门安检 → 故宫 → 打铁花（截图）
6. Demo 2：万象灵境·雅典—故宫（投影错位 → 榫卯/石作 → 来源校准 → 三条来源判断）
7. Demo 3：守境人·考据台
   - 问：按 T 提问，按位置/图鉴作答，附出处
   - 考：AI 出题 / 离线题库，答完摊开考据卡
   - 不会答也能学：看答案 + 出处链接
8. 「AI 不是聊天框，是守门人」：答不出就直说"此处无考据支撑"——把不编造做成可见机制
9. 技术架构：Canvas 程序化绘制（零素材）+ 单文件离线 + AI 考据（OpenAI 兼容，竞速 3 模型）+ 离线降级
10. 文化考据：15 张带出处考据卡（世遗文本、故宫官网、周礼、园冶、UNESCO 非遗、亚里士多德）
11. 差异化：与"城市漫步/知识卡"类作品的三个不同（代价、证据、可带走）
12. 可用性与演示：双击即玩 / 手机可看考据台 / 断网不挂
13. 可复用与落地：技能包——把"考据卡 + 出题 + 校验"抽成可移植模块，换城市/换主题即可
14. 路线图：多城（雅典/西安/泉州）、多人共建考据卡、展签分享
15. 收尾：它不宣称复原，只让人先看见，再学会怀疑

## 6 分钟演示要点（现场）

- 0:00-0:40 开场一句话 + 中轴线行走
- 0:40-2:00 午门安检 → 故宫 → 打铁花一次
- 2:00-3:20 按 T 提问 + 问一个答不出的问题（"此处无考据支撑"）
- 3:20-4:40 万象灵境：投影错位 → 两个小游戏 → 来源校准
- 4:40-5:30 考考我（AI 出题）→ 看答案 → 考据卡
- 5:30-6:00 转绘 + 展签收尾

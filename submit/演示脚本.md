# 6 分钟现场演示脚本（也用于 3 分钟录屏）

> 主线：走过一条线 → 做坏一炉火 → 校准一张标签 → 带走一幅画。

| 时间 | 画面 | 台词 |
|---|---|---|
| 0:00 | 标题页 | 这是一座会跟你对答案的北京中轴线。 |
| 0:30 | 中轴线行走 | 从正阳门到午门，路是礼制的一部分；所有画面由 Canvas 实时绘制，没有一张素材图。 |
| 1:10 | 午门安检 | 两道关：证件、行李。 |
| 1:40 | 故宫找材料 + 入夜 | 替老赵凑齐生铁、柳木炭、柳木勺；天黑了才泼得出铁水。 |
| 2:20 | 打铁花一次操作 | 打铁花是国家级非遗，铁水约 1600℃；游戏里做了安全的演出化版本。 |
| 3:00 | 按 T，问守境人 | 任何地方按 T：它知道我站在哪、解锁了什么。问“中轴线为什么是一条线”，它答，并把考据卡摊开。 |
| 3:40 | 问一个答不出的 | 问天气——它说“此处无考据支撑”。AI 在这里不是万能嘴，是守门人。 |
| 4:20 | 万象灵境 | 雅典学者把卫城数据包接进故宫沙盘，建筑没变，标签全错。 |
| 5:00 | 榫卯 + 来源校准 | 校准的不是故宫，是标签。我们做了三条来源判断：比较可以有，编造传承不行。 |
| 5:40 | 转绘页 + 展签 | 同一个场景，三种物质媒介；带走一张有题名的展签。 |
| 6:00 | 收尾 | 它不宣称复原，只让人先看见，再学会怀疑。 |

# 部署与演示说明（内部用）

## 一、给评审的线上 Demo 链接（推荐 GitHub Pages）

本地改动已提交到分支 `art-polish`（含 AI 考据台与画面升级）。在仓库目录执行：

```bash
# 方式 A：推到新分支，Pages 直接指到这个分支（推荐，不动 main）
git push origin art-polish

# 方式 B：把改动并入 main 再推（main 是 art-polish 的祖先，可快进）
git push origin art-polish:main
```

然后 GitHub → 仓库 **Settings → Pages**：
- Source 选 `Deploy from a branch`
- 分支选 `art-polish`（或 `main`）→ 目录 `/ (root)` → Save

约 1–2 分钟后生效，链接为：`https://<GitHub用户名>.github.io/<仓库名>/`
- 首页 → 开始旅程 → 按 **T** 或 HUD「问」按钮，即可体验 AI 考据台（B 方案：key 已随 `js/ai-config.js` 发布，评审可匿名直接体验在线 AI）。
- 「同境异笔」插件在 `art-demo/` 内，iframe 可打开；其 AI 转绘需要本机 Python 后端，公开链接只展示离线样例。
- 单文件版 `web.html` 也可直接双击，或用任意静态托管。

## 二、本地演示（现场市集 / 屏幕录屏）

```bash
cd zijincheng-tiehuo
node serve.js
# 打开 http://127.0.0.1:8123/
```

单文件版本：双击 `web.html` 或 `node tools/build-web.mjs` 重新生成。

## 三、考据台（AI）接入

- 桌面快捷键：`T`；或暂停菜单「问守境人 · 考据」；或 HUD 右上「问」按钮。
- 在线接入（奇绩算力，OpenAI 兼容）：
  - 打开 `http://127.0.0.1:8123/?ai=<你的key>&ai_model=<模型名>`，密钥会记在本机 localStorage，之后无需再带参数。
  - 或写入 `js/ai-config.js`：`window.WXL_AI = { key: '...', base: 'https://api.openai-next.com/v1', models: ['模型名'] };`（需在 `js/ai.js` 之前加载）。
- 无密钥 / 断网：自动降级为本地考据卡检索，演示不会中断，页面会标注「离线考据 · 无密钥」。
